Raspberry Pi ajalugu

Raspberry Pi projekt sai alguse Ühendkuningriigis eesmärgiga muuta programmeerimise õppimine noortele kättesaadavamaks. Esimene Raspberry Pi arvuti tuli müügile 2012. aastal. Sellest ajast alates on välja antud mitmeid uusi mudeleid, mille jõudlus ja võimalused on pidevalt paranenud.

Raspberry Pi areng

  • 2012 – esimese Raspberry Pi mudeli turuletoomine.
  • 2014 – Raspberry Pi Model B+ väljatulek.
  • 2019 – Raspberry Pi 4 turuletoomine.
  • 2023 – Raspberry Pi 5 turuletoomine.
